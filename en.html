A FEW THINGS TO KNOW

A few useful answers.

Is the software free to use?+

Yes. OpenSketch3D is free to use on macOS, Windows and Linux. The source code is not currently public.

Can I download it now?+

The project is in development. A public download channel and release date have not yet been announced. This page showcases current features and does not provide an installer.

Is OpenSketch3D open source?+

The source code is not currently public. The word Open in the name does not imply an existing open-source license or public source repository. Any plans to open the source will be announced separately.

Does it support SketchUp model files?+

OpenSKP enables .skp import and export; the native project format is .osk3d. SKP exchange does not cover every feature: models containing section entities must be saved as .osk3d, and model and scene shadow settings do not fully round-trip through SKP.

Can existing Ruby plugins run directly?+

The project is implementing a Ruby API with names matching SketchUp, including extension loading, a Ruby console, toolbars and HTML extension interfaces. API coverage and behavior are incomplete, so plugins need individual testing. Full compatibility is not guaranteed.

Where do these screenshots come from?+

These five screenshots were captured from OpenSketch3D on macOS. They show a box and shadows, scripted 3D text, section planes, and operation tests with large terrain and interior models. The model tests reflect specific scenes and do not represent performance for every model.
