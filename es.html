ALGUNAS COSAS QUE CONVIENE SABER

Respuestas útiles.

¿El software es gratuito?+

Sí. ModraUp es gratuito en macOS, Windows y Linux. El código fuente no es público actualmente.

¿Puedo descargarlo ahora?+

El proyecto está en desarrollo. Aún no se han anunciado el canal de descarga pública ni la fecha de lanzamiento. Esta página presenta las funciones actuales y no ofrece un instalador.

¿ModraUp es de código abierto?+

El código fuente no es público actualmente. Cualquier plan para publicarlo se anunciará por separado.

¿Admite archivos de modelo de SketchUp?+

OpenSKP permite importar y exportar .skp; el formato nativo del proyecto es .osk3d. El intercambio SKP no cubre todas las funciones: los modelos con entidades de sección deben guardarse como .osk3d, y los ajustes de sombras del modelo y las escenas no se conservan por completo al intercambiar SKP.

¿Pueden ejecutarse directamente los plugins Ruby existentes?+

El proyecto está implementando una API Ruby con nombres equivalentes a los de SketchUp, que incluye carga de extensiones, consola Ruby, barras de herramientas e interfaces HTML. La cobertura y el comportamiento de la API aún son incompletos, por lo que cada plugin requiere pruebas individuales. No se garantiza la compatibilidad total.

¿De dónde proceden estas capturas?+

Estas seis capturas se tomaron en ModraUp sobre macOS. Muestran las sombras de una casa, texto 3D creado con scripts, planos de sección, un gran modelo de terreno y dos vistas exteriores de un gran edificio comercial. Las pruebas corresponden a escenas concretas y no representan el rendimiento de todos los modelos.
