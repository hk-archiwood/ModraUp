QUELQUES POINTS À CONNAÎTRE

Quelques réponses utiles.

Le logiciel est-il gratuit ?+

Oui. ModraUp s’utilise gratuitement sur macOS, Windows et Linux. Le code source n’est pas public actuellement.

Puis-je le télécharger maintenant ?+

Le projet est en développement. Le canal de téléchargement public et la date de sortie n’ont pas encore été annoncés. Cette page présente les fonctions actuelles et ne propose pas d’installateur.

ModraUp est-il open source ?+

Le code source n’est pas public actuellement. Tout projet d’ouverture du code sera annoncé séparément.

Les fichiers de modèles SketchUp sont-ils pris en charge ?+

OpenSKP permet l’importation et l’exportation de fichiers .skp ; le format natif est .osk3d. L’échange SKP ne couvre pas toutes les fonctions : les modèles contenant des entités de coupe doivent être enregistrés en .osk3d, et les réglages d’ombres du modèle et des scènes ne sont pas entièrement conservés lors d’un aller-retour SKP.

Les plugins Ruby existants peuvent-ils fonctionner directement ?+

Le projet implémente une API Ruby reprenant les noms de SketchUp, avec le chargement d’extensions, une console Ruby, des barres d’outils et des interfaces HTML. La couverture et le comportement de l’API restent incomplets ; chaque plugin doit donc être testé. La compatibilité totale n’est pas garantie.

D’où viennent ces captures ?+

Ces six captures ont été prises dans ModraUp sur macOS. Elles montrent les ombres d’une maison, du texte 3D créé par script, des plans de coupe, un grand modèle de terrain et deux vues extérieures d’un grand bâtiment commercial. Les tests concernent des scènes précises et ne représentent pas les performances de tous les modèles.
