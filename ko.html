궁금한 점을 확인하세요.

무료로 사용할 수 있나요?+

네. ModraUp은 macOS, Windows, Linux에서 무료로 사용할 수 있습니다. 소스 코드는 현재 공개되지 않았습니다.

지금 다운로드할 수 있나요?+

현재 개발 중입니다. 공개 다운로드 경로와 출시일은 아직 발표되지 않았습니다. 이 페이지는 현재 기능을 소개하며 설치 파일은 제공하지 않습니다.

ModraUp은 오픈 소스인가요?+

소스 코드는 현재 비공개입니다. 공개 계획이 생기면 별도로 안내하겠습니다.

SketchUp 모델 파일을 지원하나요?+

OpenSKP로 .skp를 가져오고 내보낼 수 있으며 기본 프로젝트 형식은 .osk3d입니다. SKP 교환은 모든 기능을 지원하지 않습니다. 단면 개체가 포함된 모델은 .osk3d로 저장해야 하며, 모델과 장면의 그림자 설정은 SKP로 내보낸 뒤 다시 가져올 때 완전히 유지되지 않습니다.

기존 Ruby 플러그인을 바로 실행할 수 있나요?+

SketchUp과 같은 이름의 Ruby API를 구현 중이며 확장 기능 로딩, Ruby 콘솔, 도구 모음, HTML 확장 인터페이스를 포함합니다. API 지원 범위와 동작이 아직 완전하지 않아 플러그인별 테스트가 필요합니다. 완전한 호환성은 보장하지 않습니다.

스크린샷은 어디에서 촬영했나요?+

여섯 장 모두 macOS에서 실행한 ModraUp의 실제 화면입니다. 집의 그림자, 스크립트로 만든 3D 텍스트, 단면, 대형 지형 모델, 대형 상업 건축물의 두 가지 실외 뷰를 보여줍니다. 모델 테스트는 특정 장면의 결과이며 모든 모델의 성능을 나타내지는 않습니다.
